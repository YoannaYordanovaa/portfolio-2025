# AI-Powered Frontend Portfolio ⚡

This portfolio is built to demonstrate speed, efficiency, and modern UI/UX principles. 
Designed and developed with an **AI-first workflow** using React, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack
- **Framework:** React + Vite (Fast shipping)
- **Styling:** Tailwind CSS (Rapid UI development)
- **Animation:** Framer Motion (Interactive feel)
- **Workflow:** Accelerated with AI tools (Gemini/ChatGPT) for logic and structure optimization.

## 💡 Philosophy
Reflecting the mindset of a Creator who uses AI as leverage to deliver results in hours, not weeks.
Focus on clean code, responsive design, and "alive" interfaces.

## 🛠️ Setup
1. Clone the repo
2. `npm install`
3. `npm run dev`
